# 20260304-【Cesium】实现流动线条

## 需求效果

需求效果是：热带扰动路径点和台风点之间，画出一条流动的线条连接两个点。

## 核心代码

![image-20260304184131303](https://files.seeusercontent.com/2026/03/04/hA4x/image-20260304184131303.png)

```js
      // 绘制流动线
    drawFlowLine(point1, point2, id) {
      if (!point1 || !point2) return;
      const polylineTrailMaterialProperty = new Cesium.PolylineTrailMaterialProperty({
        color: Cesium.Color.fromCssColorString('#36FCFF'),
        duration: 3000,
        trailImage: require('@/static/faderCyan.png')
      });

      const dataSources = this.getDataSources(`his_typhoon_flowline_${id}`);
      dataSources.entities.add({
        id: 'flowLine-' + id,
        hidePopup: true,
        polyline: {
          positions: Cesium.Cartesian3.fromDegreesArray([point1.lng, point1.lat, point2.lng, point2.lat]),
          width: 4,
          material: polylineTrailMaterialProperty
        }
      });
    },
```
