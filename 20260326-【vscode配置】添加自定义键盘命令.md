# 20260326-【vscode配置】添加自定义键盘命令

## 打开键盘配置json文件

在 VS Code 里这样打开 keybindings.json：

1. 按 Ctrl+Shift+P
2. 输入并执行 Preferences: Open Keyboard Shortcuts (JSON)

也可以：

1. Ctrl+K 然后 Ctrl+S 打开快捷键页面
2. 右上角点 {} 图标（Open Keyboard Shortcuts (JSON)）

## 添加自动eslint fix 命令

```json
{
  "key": "ctrl+alt+f",
  "command": "editor.action.sourceAction",
  "args": { "kind": "source.fixAll.eslint" }
}
// 或者
 {
    "key": "alt+v",
    "command": "eslint.executeAutofix"
  }
```

## 添加自动格式化

```json
 {
    "key": "alt+g",
    "command": "editor.action.formatDocument",
    "when": "editorHasDocumentFormattingProvider && editorTextFocus && !editorReadonly && !inCompositeEditor"
  },
```
